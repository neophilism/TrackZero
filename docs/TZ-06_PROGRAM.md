# TZ-06 program sequencing primitive

Pure immutable reorder operation for song, ad, intro and recurring block rows. No drag/drop interface, persistence, entitlement or radio-engine scheduling connection. The frontend needs keyboard-reordering equivalents, list announcements, ARIA affordances, undo, and explicit save failure handling. Backend must check broadcaster roles, program rights, conflicts, schedule versions and transactional writes. A sequence move does not authorize broadcast.
