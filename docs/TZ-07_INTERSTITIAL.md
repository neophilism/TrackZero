# TZ-07 interstitial draft contract

The interstitial draft validator is an in-memory, provider-free metadata boundary for prospective station/content identifications. It accepts bounded duration, a claimed audio type, a digest and capture provenance. These fields are user-provided claims, not measured or authenticated evidence. All accepted drafts remain quarantined and not publishable. No sound is uploaded, scanned, encrypted, stored, played or routed by this contract.

A completed artist studio still requires authenticated broadcaster roles, actual authorized-endpoint media ingest, rights proof, preview, moderation and rights-based release, accessible record/upload controls, and compatible scheduler integration. Tests use synthetic metadata only; no actual field, provider or release acceptance is claimed.
