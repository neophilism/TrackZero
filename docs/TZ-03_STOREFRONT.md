# TZ-03 station identity and storefront shell

The current branch validates public station metadata and renders an accessible, static catalog preview. It escapes all station and offer text, renders artwork only from configured HTTPS origins, and never shows purchase or playback controls. An empty catalog has an explicit status. `node --test tests/storefront.test.mjs` covers valid, denied, hostile-text, hostile-URL and empty-catalog cases locally.

This is an inert view model and HTML renderer. No authenticated station owner, rights proof, live catalog source, payment flow, entitlement, streaming access, or production release exists in this repository. The original TZ-03 plan depends on TZ-02, whose provider and engine integration is incomplete; imported registry dependencies are empty and do not establish that acceptance. A trusted backend must independently verify station ownership, catalog availability and rights before publishing offers or enabling any transaction. The existing planning CI does not run this product test suite, and its configuration is a protected path under the Boardroom gateway.
