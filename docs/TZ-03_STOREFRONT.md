# TZ-03  Station identity and storefront shell

This initial dependency-free view-model validator distinguishes public broadcaster identity, station description, artwork URL and explicitly available complete-product offers. It does not create a live storefront, payment flow, streaming access, licensing proof or broadcaster authorization. Do not display inactive catalog entries as purchasable. Future client UI must escape all text, validate image hosts, expose accessible product descriptions and handle unavailable catalogs without misleading purchase buttons. A trusted backend must independently verify station ownership, actual rights, catalog availability and service identity before publishing an offer. Pending: accessible rendered UI, service integration, denied cross-role edits, interrupted/empty catalog E2E tests, and real field evidence for hardware-related claims.
